NEIS 인증키 발급 방법

방학 D-day와 급식을 자동으로 불러오려면 필요해요 · 2~3분 · 완전 무료

날씨·미세먼지는 인증키 없이도 나오지만, 방학 D-day와 오늘 급식은 교육부 NEIS 자료라 인증키가 있어야 제대로 불러옵니다. 키가 없으면 자료가 5건만 와서 방학이 안 잡혀요.
  1. open.neis.go.kr 접속 → 로그인 open.neis.go.kr 에 들어가 오른쪽 위 로그인을 누르고 구글·카카오·네이버 중 편한 계정으로 로그인합니다. 따로 회원가입은 없어요.
  2. 활용가이드 → 인증키 신청 상단 메뉴에서 활용가이드 → 인증키 신청 을 클릭합니다.
  3. 신청서 작성 서비스명은 아무거나(예: 우리반 그물), 활용 용도는 정보 열람·확인 쪽을 고르고 소속·사용자 유형은 본인에 맞게 채웁니다. 데이터는 학교기본정보 · 급식식단정보 · 학사일정을 선택하면 됩니다.
  4. 신청 → 즉시 발급 신청 버튼을 누르면 인증키가 바로 만들어집니다. 승인 대기 없음.
  5. 마이페이지에서 키 복사 마이페이지 → 인증키 발급 내역에서 영문·숫자로 된 긴 문자열을 통째로 복사합니다.
  6. 그물 설정에 붙여넣기 그물 화면에서 ⚙ 설정 → NEIS API 키 칸에 붙여넣고 저장을 누르면 끝입니다.
참고
  • 완전 무료입니다. 교실 화면 1대 정도면 사용량 제한은 신경 쓰지 않아도 돼요.
  • 입력한 키는 그 브라우저에만 저장되고, 그물 파일이나 서버로는 전송되지 않습니다.
  • 키를 넣은 뒤에도 방학이 안 보이면 설정 → 데이터 관리 → “캐시 전체 삭제” 후 새로고침하세요.
